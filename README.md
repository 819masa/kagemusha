# Kagemusha（影武者）

任せた AI の前に立つ関所を、給料日の一日として遊ぶ模擬です。

2032年、佐藤ハルは家計・仕事・キャリアの Mind に暮らしを任せています。Kagemusha は、その Mind が動く直前に割り込みます。プレイヤーは現場を見て、**守る**（遮断・記録・通報・目印つきのおとり）、**欺く**（隔離した偽物だけで相手の手口を引き出す）、**反撃**（将来・if。証拠を公的機関へ渡す下書き）を選びます。攻撃元への侵入は、選んでも実行されません。

実在のメール、店、ウォレット、MCP、モデルには接続しません。攻撃も防御も、この画面の中だけです。

発想の元は、Minds ideathon 提出資料（Kagemusha、2026年10月）です。要件は [docs/requirements.md](docs/requirements.md) にあります。

## 必要環境

- Node.js 22 以上
- npm

## 動かし方

```bash
npm install
npm run dev
```

表示された URL（既定は `http://localhost:5173/`）を開きます。

```bash
npm test          # 配点と、侵入が場面を進めないことの確認
npm run build     # 静的ファイルを dist/ に出力
npm run preview   # dist/ をローカルで配信
```

## 遊び方

1. タイトルから導入を読み、07:20 の給与から始めます。
2. Mind がメール、店、回線、投稿、請求、スキル、ウォレット、割り勘を進めます。手元のボタンを押すと、実行の直前で関所が割り込みます。急ぐときは「関所へ」。
3. 薄い文字のある場面は「影で読む」。関所に入る前に読むと点が少し増えます。
4. 守る / 欺く / 通す、を選びます。数字キーでも選べます。反撃は最後の番号です。
5. 反撃の「侵入」は拒否されます。措置の下書きは、目の前の操作を止めないことがあります。先に守ってください。
6. 22:00 のまとめで、遮断・確認・おとり・免疫・被害・誤検知・評価を見ます。通報の下書きは開けますが、送信はできません。

正規の電気代まで止めると、守りは強くても誤検知になります。

## 画面

| 画面 | 内容 |
| --- | --- |
| タイトル / 導入 | 三段階と、ハルの Mind |
| 現場と関所 | 八つの時刻。スコアと、防いだ額 |
| 権限の台帳 | 上限、確認役、スキルの状態 |
| 判断ログ | 自律の遮断と、選んだ行動 |
| 夜のまとめ | 守った / 聞いた / 攻めた / 配った |
| 通報下書き | 時刻、相手、要求だけ。未送信 |

## デプロイ

ビルド結果は `dist/` です。API も環境変数も要りません。

- Vercel: フレームワークは Vite、出力は `dist`。リポジトリを取り込むだけで配信できます。
- GitHub Pages: `npm run build` の `dist/` を公開します。`vite.config.ts` の `base` は `"./"` なので、プロジェクトサイトのサブパスでも相対パスのまま動きます。

## リポジトリの中

```text
docs/requirements.md   要件定義
src/game               場面、配点、状態
src/components         画面
```

配点の閾値や加点はデモ用の仮説です。判断の優劣（どの選択が場面に合うか）は要件定義の第5節を正とします。
